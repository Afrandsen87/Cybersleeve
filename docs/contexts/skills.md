## Design (from DESIGN.md)

### 8. Skills

Skills are buyables paid in **skill points**, drawn as a **skill tree** on the Skills tab: three branches, each a lane growing sideways (roots on the left, each skill to the right of the one it needs, a line from every parent to its child; a parent is always in the same branch), with a neon colour under each lane: **Cybernetics** (green), **Anonymity** (red, the heat skills) and **Leverage** (brown, Kompromat). All three roots (Overclocked Cortex, Cold Trail, Nose for Secrets) can be started from the first skill point. **The whole tree is always shown**, every icon and every branch title, but what a skill says stays hidden (`???`, a `?` icon) until it is readable: its own gate is owned and every parent is readable, so a child of a hidden skill is hidden too. A readable skill whose parent is not owned shows its real text, dimmed, and cannot be bought yet. The re-sleeve skills are drawn the same way, in one lane. The tree: The layout rule: the root is centred vertically on the whole lane, and every path is its own straight lane on its own row, so no line overlaps another. Cybernetics = Overclocked Cortex, then three lanes: Bandwidth Leech, which splits into two lanes (Signal Amplifier, Overdrive Spike above Fiber Tap, Backbone Parasite); Muscle Memory, Quick Study; Parallel Threads, Neural Accelerant; Anonymity = Cold Trail, which splits into three lanes (cooling: Obfuscation, Purge Protocol, then the end skill Blackout; Burn leads: Scorched Earth, Silver Tongue; idle: Quiet Hours, Undercover); Leverage = Nose for Secrets, then Deep Files (then Sealed Archives, then Black Ledger), Exploit Kompromat (then Dossier) and Back Channel Deals (then Tiered Informants, Double Agent, Deep Cover; Moles belong to the Kompromat chain, not to anonymity). **Points:** none at the start; 1 when the total of all ACTION levels reaches 1, then one more per order of magnitude of that total (2 at 10, 3 at 100, 4 at 1,000, ...); sleeve levels do not count. Each skill costs 1 point for now. Points available = points earned − cost of the skills owned, so nothing is stored. Skills reset by re-sleeving with the action levels they depend on (ASSUMPTION). **A skill is readable only once the purchase that makes it useful is owned** (and its parents are readable): the Kompromat skills (Nose for Secrets, Exploit Kompromat, Back Channel Deals) need Kompromat harvest, Obfuscation needs Push malware's Overclock, Scorched Earth and Silver Tongue need the Burn leads purchase, and Deep Cover sits at the end of the Back Channel lane (Moles only come from there). Quiet Hours and Undercover are readable from the start.

| Skill (names are made up) | Effect |
|---|---|
| Overclocked Cortex | Interface speed ×1.25 |
| Bandwidth Leech | Node payout ×1.5 (compounds with the Node payout buyable) |
| Cold Trail | Heat cools down 25% faster |
| Muscle Memory | Hacking Proficiency counts 25% higher wherever it is used (hacking multiplier, drop-ratio shifts, and the value shown on screen) |
| Quick Study | Every ACTION level needs 1% less XP (sleeve levels unchanged), capped by `progression.maxSleeveXpReduction` (Study methods is not: it is a divisor with no ceiling) |
| Parallel Threads | Interface speed ×(1 + ln(nodes) / 500): very slow on purpose (about ×2.4 at the 1e308 cap; Network synergy's 1/100 gives about ×8). Stacks with Network synergy. |
| Neural Accelerant | Interface speed ×(1 + 5% for each distinct rarity of augment applied on any action), additive: Common alone is ×1.05, Common and Uncommon ×1.10, all five ×1.25. Counts rarities, not copies. |
| Fiber Tap | Each completed Push malware run has a **25% chance to also pay one full Grow network reward** (its reward, its own multipliers, its reward kind; whole nodes only, so never a fraction). Never critical, no XP, heat or drops. Drawn once per batch of runs. |
| Backbone Parasite | Multiplies the Grow network reward by `1 + 2.263 × ln(1 + action level / 18)`, where the level is the plain action level of Grow network: about ×2 at level 10, ×4 at 50, ×5.3 at 100, ×10 at 1,000 (concave: ever flatter). Replaces nothing: stacks with Parallel nodes. |
| Signal Amplifier | Every critical success has a **5% chance to bring one extra critical success**, free (the extra does not roll again). Applies to every action; extras bank critical links, feed the highlight and pay like any critical success. |
| Overdrive Spike | Doubles the **reward** of every critical success (×3 becomes ×6; it stacks with the other critical boosts). The XP of a critical success is unchanged. |
| Nose for Secrets | Doubles the Kompromat base drop chance (the result is at most 100%) |
| Exploit Kompromat | Node payout ×(1 + 1% per rare Kompromat file held) |
| Deep Files | Adds **0.1** to the drop weight of the **rare** Kompromat rarity (weights add up to 100, so 0.1 percentage points), after the Hacking Proficiency shifts. Rare cannot drop at first (weight 0) |
| Sealed Archives | Same for **legendary**: +0.1 to its drop weight; child of Deep Files |
| Black Ledger | Same for **crisis level**: +0.1 to its drop weight; child of Sealed Archives |
| Dossier | Node payout ×(1 + 5% per legendary Kompromat file held); child of Exploit Kompromat |
| Back Channel Deals | Adds a **Back channel** button beside Sell and Sell all: with the common Kompromat stack selected, each press gives up one file for **5 Moles** |
| Tiered Informants | Back channel takes every rarity, and a file pays 5 Moles × its position in the rarity list (common ×1, uncommon ×2, rare ×3, legendary ×4, crisis ×5); child of Back Channel Deals |
| Double Agent | Back channel pays twice the Moles for every rarity; child of Tiered Informants |
| Obfuscation | Push malware's Overclock makes **2x** the heat per heat-making run instead of 3x (the factor is lowered, never raised; other actions are not affected). |
| Scorched Earth | Each Burn lead takes **1 more point of heat** away, after its 5% (heat never goes below 0). Auto Burn counts it when working out how many leads it needs. |
| Silver Tongue | Burn leads drop **50% more often** (the Burn lead drop chance is multiplied by 1.5). |
| Quiet Hours | While **no action is in progress**, heat cools **5 times as fast** (a placeholder strength; it may need to be much higher). "In progress" means an action is running: a manual action that has finished its run and waits does not count. Everything is read at the start of each slice of game time. |
| Undercover | Quiet Hours also counts while **Grow network** is running **without Overclock**. Any other running action, or Grow network with Overclock on, still stops the idle cooling. Does nothing without Quiet Hours. |
| Deep Cover | **Moles are not spent any more.** They add up, and heat cools **5% faster (multiplicative) for every order of magnitude of Moles held** (`1.05 ^ log10(Moles)`; nothing at 1 Mole or fewer). The Moles' own cooldown boost no longer applies. Back Channel Deals still gives Moles. |
| Blackout | The end skill. **The heat tax takes at most half** of node income, however much heat there is (the cap is `1 - 0.5`; ICE Rating still lowers the tax below it). Node credits therefore never stop. |
| Purge Protocol | Every heat cooldown cycle removes **1 more heat per sleeve level of Build Legend**. The cycles are not faster, so the cooldown still completes in discrete steps and the bigger step applies from the first cycle after the skill is bought. A late-stage skill, part of removing the heat tax. |

**Moles.** A Mole is one point of heat that cools **200% faster (three times the pace)**, on top of Cold Trail. While there are Moles and heat, every point of heat cooled uses up one Mole; with none left the heat cools at the normal pace. Moles are kept while there is no heat, and reset by re-sleeving. With the **Deep Cover** skill they are no longer spent (see the skills table).

## Decisions (from docs/DECISIONS.md)


*Group: Decided 2026-10-25 (by the user, items)*
- **Tabs and skills (2026-10-25):** the game has two tabs, Character (everything so far) and Skills (a box of skill buttons; a whole skill tree comes later). Skill points: none at the start, the first when an action reaches level 1, then one per order of magnitude of the total of all ACTION levels (1 at a total of 1, 2 at 10, 3 at 100), 1 point per skill for now. Skills are buyables paid in the `skillPoints` currency (nothing is stored: points available = earned - cost of the skills owned). Back Channel Deals gives Moles (a Network counter) by giving up common Kompromat; Moles make heat cool faster. Skills reset when re-sleeving (assumption).

*Group: Decided 2026-10-27 (by the user, Corporation and item tuning)*
- **Skill tree (2026-10-27):** the regular skills become a skill tree with three branches drawn as sideways lanes: **Cybernetics** (green; was "speed"), **Anonymity** (red; was "heat") and **Leverage** (brown, Kompromat). All three roots are open from the first point; there is no lock-out between branches (the scarcity of skill points is the choice). The re-sleeve skills are drawn sideways in the same widget. **Skills are exempt from the "nothing is shown before it matters" rule:** every node, icon and branch title is always shown, and only the text is hidden (`???`, `?`) until the skill is readable. Readable = its own gate (`requires`, the purchase that makes it useful) is owned AND every parent is readable (a child of a hidden skill is hidden); a readable skill whose parent is not owned shows its real text, dimmed. A parent must be in the same branch as its child (validated), so every parent-child pair is drawn as a line; there are no cross-branch parents. `requires` stays the reveal gate and a new `parents` field is the tree edge, because the two meant different things on the same field; core enforces both for buying and loading a save, the view tells them apart. Layout is pure data (`branch`, `parents`): column = depth, row = the parent's row when free; nothing is measured on the page. Consequence: a saved game that owns a skill below an unowned parent has that skill dropped on load (its points are refunded, as points are derived).

*Group: Decided 2026-10-27 (by the user, Corporation and item tuning)*
- **Cybernetics skills (2026-10-27, by the user):** six skills added to the Cybernetics lane, so Overclocked Cortex has three arms: Bandwidth Leech (then Fiber Tap, then Backbone Parasite; and Signal Amplifier, then Overdrive Spike), Muscle Memory (then Quick Study) and Parallel Threads (then Neural Accelerant). **Parallel Threads** reuses `interfaceSpeedPerLnNodes` at `perLn` 0.002 (very slow on purpose; Network synergy is 0.01). **Neural Accelerant** is `interfaceSpeedFromAugmentRarities`: +5% per distinct rarity of augment applied anywhere, additive (max x1.25 with five rarities). **Fiber Tap** is `paysActionReward`: a Push malware run has a 25% chance to also pay one WHOLE Grow network reward (no fractions, because half a node cannot be paid and early in a sleeve it would round to nothing); never critical. **Backbone Parasite** is `rewardMultiplierFromActionLevel` on the Grow network ACTION level (not the access level) with a log curve, `1 + 2.263 ln(1 + level / 18)`: about x2 at level 10, x4 at level 50, then flatter (a power curve through the same two points was rejected because it keeps climbing fast). **Signal Amplifier** is `criticalExtraChance`: each critical success has a 5% chance of one extra free critical success (the user first said "a 3x crit", then corrected it to an extra free crit); the extra does not roll again. **Overdrive Spike** is `criticalRewardMultiplier` x2: the reward of every critical success only, on all actions (not XP). Dropped from the first brainstorm: Thermal Sink, Redline Governor, Packet Skimmer, Pattern Recognition and the rest. Skills cannot have an `actionId`, so the cross-action effects are sleeve-wide and name their source and target actions.

*Group: Decided 2026-10-27 (by the user, new Anonymity skills)*
- **Anonymity branch shape:** Cold Trail splits into four paths: cooling (Obfuscation, Purge Protocol), Burn leads (Scorched Earth, Silver Tongue), idle (Quiet Hours, Undercover) and Moles (Deep Cover), with the end skill Blackout needing Purge Protocol, Undercover and Deep Cover. Only the skills the user picked were built (Static Noise, Spoofed Origin, Burn Notice, Burrow, Sleeper Cell and Dead Drop were left out). Each costs 1 skill point.
