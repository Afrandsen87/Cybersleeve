  • A · Trees: each daemon's firmware tree is the Firmware page's branch card: header with count and segments, the four node states (installed, affordable, available, locked) with cost badges, lit and hover-path lines, and the install sweep. Every icon is distinct: Kompromat nodes are a file in the rarity's colour with a coin (autosale) or a handset (Back Channel) badge; Dispersal nodes are a schematic in the rarity's colour, or a crosshair whose pips count the slot it adds.
  • Hover a node and the control it added (or will add) gets a dashed outline; installing one makes the new control flash once. This ties each tree node to what it does on the panel.
  • Inspector (default: docked): hidden until you hover or click a firmware node. Then that lane shrinks to the compact width and the inspector opens in the freed space beside it, always the same height whichever firmware it shows (sized to the longest one), with every section present and no scrollbar; a shorter lane grows to fit it. Hover previews; click pins it (✕, Esc or clicking the node again unpins). With a firmware pinned, leaving any node returns the pane to the pinned one at once, so nodes you pass over on the way to INSTALL never take it over. With nothing pinned, moving from the node into the inspector keeps the preview open. Hovering a node in another lane moves the pane there; the preview stays while you are in that lane and the pane returns to the pinned lane when you leave it. Nothing under the cursor moves: a row the pane leaves keeps its height while it sits above the cursor, and while lanes resize the page scrolls so the node under the cursor stays put. It is the Firmware page's pane with an extra ADDS line. The other two options above: an always-on side pane, or tooltips with click-to-buy (the Firmware plan's current choice for this tab).
  • B · Kompromat: two protocol rows in Auto Burn's style, in the order the game runs them: BACK CHANNEL first, then AUTOSALE. Chips are rarity-coloured with an LED and show how many files you hold. Without Back Channel Deals the BACK CHANNEL row still shows (you bought it) but its chips are disabled and it says what's missing. Rarities you haven't bought don't show; the tree shows what's coming.
  • C · Dispersal: a status line with a slot meter, a PERMITS row of rarity pills and a TARGETS row of action chips. When every slot is used, the unpicked chips go dim. In the Late state you'll see 6 slots for 5 actions: the last Dispersal Target does nothing (content oddity, left as is).
  • D · Chrome: every daemon is a .panel with a // header in its branch colour and an ONLINE/OFFLINE tag. Before its root firmware is installed, a panel shows only its tree and a one-line note.
  • Auto Burn fixes carried into the plan: (1) the status line says the toggle state once (no trailing "Inventory toggle OFF"); (2) heat uses the Sleeve heat formatter (here: 1.36K) and the overflow label right-aligns inside the panel. Drag Heat past 105 to see it.
