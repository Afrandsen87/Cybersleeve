# Automation and attention

**DRAFT.**

- Automation is a reward, not a default. The first run of anything is manual; buying automation turns a chore into a number.
- A good automation upgrade removes a repeated action and leaves a decision. "Auto-buy the cheapest" removes a chore; "choose what auto-buy prefers" adds a decision.
- Order of automation: auto-run, auto-buy, auto-reset thresholds, then smart settings (per-action rules). Each is bought with something scarce (Cybersleeve: automation points).
- Do not add a chore at the same layer the player just automated. If a new system needs babysitting, it must be automatable soon.
- Quality-of-life ladders (bulk buy, max buy, hotkeys, filters) belong early; the player should not need to ask for them.
- Idle time is the baseline. A mechanic that only pays when the player is actively present is an optional bonus, never the main path (Cookie Clicker's golden cookies are the model: a bonus on top of idle production, though Cybersleeve avoids clicking).
