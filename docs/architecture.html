At a glance

An installable idle game (PWA) in strict TypeScript. Game rules are framework-free and run against injected interfaces; the browser is only a thin shell.

Pure core

core/ has no DOM, timers or storage. Time enters only through GameEngine.tick(deltaMs), so the whole game is deterministic and unit-testable.

Big numbers by interface

All amounts are BigNum. One adapter file wraps break_infinity.js; swapping the library touches nothing else.

Data-driven content

Actions, buyables and tuning are plain data in content/gameConfig.ts. New content is data, not code.

Level rule

Levels start at 0 and every level costs its own full amount: cost(leaving level n) = firstLevelXp × growthFactor^n, and the XP inside a level starts again at each level-up (stored as one running total; the part inside the level is derived). Defaults: 10, then 100, then 1000 more, so the totals are 10, 110, 1110, … Both numbers are configurable, per track (each action and each action's own sleeve level). A logarithm gives the estimate, which is corrected against exact totals, so boundaries are exact and valid far beyond the double range.

Speed & rewards

speed    = f(actionLevel) × f(sleeveLevel) × interfaceSpeed × global.speed
           f = linear: 1 + (L−1)×perLevel   (default: = L)
               exponential: base^(L−1)
duration = baseDuration / speed
per run  = reward × (nodes, if rewardPerNetworkNode) × rewardMultiplier
           credits are also multiplied by global.creditMultiplier (the only reward lever); heat does not tax a run's
           reward; every other reward kind is not scaled either
passive  = network nodes × (creditsPerNodePerSecond + nodePayoutBonus) × global.creditMultiplier × nodePayoutMultiplier (buyables) × (1 − heat × heatTaxPerPoint)  credits per second
heat     = sleeve.baseHeat, + heatPerRun per completed run, − heatCooldownAmount per heatCooldownMs while heat > 0 (reset by re-sleeve)
           xpPerRun × global.xp XP (reward multipliers do not touch it)
rewardMultiplier = ∏ factor^copiesOwned (scales the action's own reward per run only)
sleeve XP (per action): +sleeveXpPerGrant per runsPerSleeveXp runs of that action

Worked example (level worth 0.05 per level): action level 2, sleeve level 1, interface speed 1, base 10 s → 10 s / (1.1 × 1.05) = 8.66 s.

Configuration
